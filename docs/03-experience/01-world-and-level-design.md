## 연두항 창업지구

항구 도시 연두항은 새 주민이 작은 사업을 시작할 수 있도록 빈 상가와 공동 작업 공간을 정비했다. 플레이어는 창업지구 입주 프로그램에 참여해 첫 사업을 연다. 주민은 단순한 보상 배달자가 아니라 예산·취향·납기·요구 조건이 다른 고객으로 등장한다.

안내 담당 ‘하나’는 시작 절차와 결과 회고를 돕고, 설비 담당 ‘모루’는 업그레이드와 유지보수를 안내한다. 지원 담당 ‘단’은 연습 고객과 복구 작업을 맡는다. 이들은 경쟁 점수나 구매를 조작하지 않는다.

스토리의 장기 질문은 ‘얼마나 큰 회사를 만들었는가’와 함께 ‘어떤 약속을 지키는 사업인가’다. 선의만으로 원가나 수요가 해결되지 않고, 효율만으로 고객의 요구가 사라지지도 않는 상황을 만든다.

## 스테이지 공간 기준

공통 공간 단위는 미터다. 구현 엔진의 단위 변환은 어댑터가 담당한다. 아래 치수는 회색 상자 시제품의 시작값이며 이동·카메라 테스트 뒤 조정한다.

| 구역 | 위치와 크기 기준 | 플레이 기능 |
|---|---|---|
| 중앙 보행가 | 전체 120×90m 안의 가로축, 기본 폭 8m | 실제 플레이어와 고객이 보이는 중심 |
| 북측 상가 3개 | 각 필지 20×16m | 업종 자유 선택 가능한 동일 기본 공간 |
| 남측 상가 3개 | 각 필지 20×16m | 북측과 동등한 접근성, 자산 가격 차등 없음 |
| 사업 실내 | 각 필지 안 기본 16×12m | 핵심 설비·고객 접점·전시·연구 구역 |
| 안내 광장 | 중앙 진입 지점 | 업종 체험, 상권 보고, 방문 안내 |
| 공동 지원실 | 보행가 끝 | 설비 설명, 연습, 회복 가능한 기초 작업 |
| 도시 출입구 | 양끝 포털 | 고객 유입·외부 선택의 시각화 |

6개 필지의 중앙 접근 거리 차이는 초기 배분 점수에 넣지 않는다. 물리적 자리 선점이 수요를 독점하지 않게 하고, 추후 입지 모델을 추가하면 별도 가격·장단점을 공개한다.

## 공간 배치 규칙

- 배치 격자 0.5m, 기본 회전 90도. 건물 외곽·출입구·필수 작업 지점을 침범하지 않는다.
- 고객 접근 통로 목표 폭 2m. 폭 숫자 확인과 실제 경로 검사를 함께 한다.
- 기능 가구의 작업 접점, 고객 대기 접점, 충돌 영역을 콘텐츠로 정의한다.
- 장식과 유료 외형은 기능·점유 영역·이동 방해를 바꾸지 않는다.
- 서버가 보유·수량·필지 소유·겹침·경로를 검증한 뒤 배치를 확정한다.
- 소프트웨어와 SI 사무실에도 상담 데스크·제품 시연·검수 공간이 있다. 손님이 없는 산업으로 보이지 않게 한다.

고객 NPC가 실제 출입구에 도착하는 연출과 거래의 권위는 분리한다. 화면의 NPC 이동이 일시 멈췄다고 자동으로 매출이 사라지거나 지급되지 않는다. 수요를 배정할 때 서버가 통로와 서비스 가능성을 확인하고 이후의 작업 상태를 따른다.

## 업종별 공간 읽기

| 업종 | 밖에서 보이는 정체성 | 내부의 주요 작업 접점 | 성장의 시각 변화 |
|---|---|---|---|
| 카페 | 메뉴 보드, 좌석, 음료 준비 | 주문대·커피 설비·점검대 | 안정된 제작 동작, 연구 메뉴 설명, 테마 |
| 음식점 | 오늘의 메뉴, 준비 수량 | 전처리·조리·배식·위생 점검 | 정돈된 동선, 보관 설비, 완성도 |
| 소프트웨어 | 제품 시연 화면, 해결하는 문제 | 요구 조사·구현·테스트·지원 | 기능 카드, 테스트 결과, 고객 사용 장면 |
| SI | 상담·프로젝트 진행 보드 | 범위 합의·작업·검수·변경 협의 | 진행 이력, 완수한 고객 사례, 검수 공간 |

## 고객과 상권의 시각 정보

머리 위에는 필요한 경우에만 ‘기다림’, ‘요구 조건’, ‘상담 중’ 아이콘을 표시한다. 모든 고객에게 떠다니는 숫자를 붙이지 않는다. 가게의 잠재 고객은 메뉴·시연·대기 상황을 보고 관심을 나타낸 뒤 방문하거나 지나간다.

다른 사업의 정확한 내부 원가·고객 개인정보·미공개 연구 선택은 볼 수 없다. 공개 정보는 가격, 영업 상태, 대표 제품, 요약 명성, 외관과 실제 대기 정도다. 경쟁 분석 화면은 관찰 가능한 정보로 구성한다.

## 단계별 레벨 디자인

1. **도입 공간:** 안전한 공통 광장에서 네 업종을 동일한 화면 크기로 비교한다.
2. **개인 기초 공간:** 튜토리얼 수요로 작업·원가·마감을 배운다.
3. **경쟁 상권:** 동등한 성장 구간의 이용자와 공유 수요를 경험한다.
4. **첫 개선:** 손님을 놓친 원인에 맞춰 연구 또는 운영 개선을 실행한다.
5. **선택의 결과:** 업종 사건과 후속 고객 반응을 통해 개선을 검토한다.
6. **공개 전시:** 운영 성과를 기념품·설명·공간 변화로 보여 준다.

단계는 공간을 계속 넓히는 것만으로 표현하지 않는다. 동일 장소의 동선, 장비, 고객 행동, 결과 보드가 달라지게 한다.

## 환경 제작 목록

공통 상가 외곽 1종과 내부 레이아웃 4종, 광장·보행로, 고객 6개 시각 변형, NPC 안내원 3명, 업종 핵심 설비, 작업·유지보수·연구 애니메이션, 아이콘과 간판 템플릿을 먼저 만든다. 장비의 3단계는 기능 점검 후 실루엣과 작은 동작 차이로 구별한다.

초기 성능 예산은 동시 표시 고객 36명 수준에서 검증을 시작한다. 논리 고객 수와 표시 모델 수를 분리하고 멀리 있는 상담·대기 상태는 집계 표시한다. 이 숫자는 구현 성능의 보장이 아니다.

## 레벨 검증

- 모든 필지에서 입장·핵심 설비·고객 접점·출구까지 이동 가능하다.
- 정상적인 배치에서 카메라가 벽이나 천장에 가려 핵심 버튼을 잃지 않는다.
- 명성·유료 테마와 무관하게 첫 거래에 필요한 위치는 접근 가능하다.
- 경쟁자가 없는 서버와 6명이 모인 서버 모두 ‘왜 손님이 오는가’를 이해할 수 있다.
- 다른 플레이어의 아바타가 입구에 서서 경제 활동을 차단할 수 없다.
