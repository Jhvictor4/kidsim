## 공통 용어

| 용어 | 뜻 | 혼동하면 안 되는 것 |
|---|---|---|
| 스테이지 | 최대 6명의 사업과 한정 수요를 처리하는 실시간 상권 인스턴스 | 세계 전체 영구 도시 |
| 사업 | 플레이어가 운영하는 하나의 경제·평판·연구 단위 | 계정의 모든 소유 아이템 |
| 경영일 | 스테이지의 20분 보고 주기 | 현실의 하루 또는 강제 완주 라운드 |
| 활성 경영 시간 | 플레이어가 연결된 정상 사업의 논리 시간 | 미접속 벽시계 시간 |
| 유상 운영 시간 | 고정비가 누적되는 영업·잔여 업무 처리 시간 | 단순 접속 시간 |
| 수요 토큰 | 한 번의 구매 필요를 가진 서버의 고객 기회 | 화면에 보이는 NPC 모델 |
| 외부 선택지 | 다른 업체 이용 또는 이번 구매 포기 | 반드시 플레이어에게 배분할 고객 |
| 실제 품질 | 납품 결과의 공정·검증·상태를 평가한 값 | 외관이나 광고로 보이는 품질 |
| 시장 적합성 | 고객의 현재 필요에 제품이 맞는 정도 | 일률적인 연구 레벨 |
| 신선함 | 새로운 제안이나 변화에 대한 관심 | 오래되었다는 이유로 생기는 물리적 불량 |
| 명성 | 검증된 서비스 결과에 기반한 신뢰의 추정 | 좋아요 개수·DG 소비량 |
| 영업 약속 | 영업 예고에 고객 예약이 확정되거나 거래로 성립한 서비스 약속 | 고객 예약 없는 정상 휴업 |
| 선택 사건 | 조건·선택지·비용·후속 효과를 가진 서사 단위 | 모델이 임의로 만드는 경제 명령 |
| 사건 감독 | 조건과 쿨다운을 보고 허용 사건을 선택하는 시스템 | 플레이어에게 항상 이기는 경쟁 AI |
| TC | 플레이로 얻는 사업 자금 | 현금으로 환급되는 자산 |
| DG | 실화폐 구매를 통해 얻는 표현용 유료 재화 | 고객 유치 성능 또는 연구 가속 |
| PB | 특정 의뢰에만 쓰는 임시 예산 | 개인 TC 지갑 |
| XP | 쓰지 않고 누적하는 성장 값 | 명성과 고객 만족도 |
| 원가 예약 | 거래 수행에 필요한 TC를 사용 불가 상태로 확보 | 이미 소모된 재료비 |
| 공헌이익 | 매출에서 거래 변동비를 뺀 값 | 고정비와 연구비까지 뺀 순이익 |
| 원장 | 재화·소유 변화의 확정 기록 | 화면에 임시 표시한 숫자 |
| 멱등 처리 | 같은 요청을 다시 받아도 같은 거래를 한 번만 적용 | 요청 자체가 한 번만 도착한다는 보장 |
| 권위 세대 | 현재 스테이지를 변경할 수 있는 서버 소유 세대 | 클라이언트 버전 |
| 콘텐츠 버전 | 가격·조건·선택지를 재현하는 정의 버전 | 게임 앱 설치 버전만의 의미 |

## 어떤 값을 어디서 바꾸는가

| 변경 주제 | 유일한 기준 문서 | 반드시 함께 확인할 문서 |
|---|---|---|
| 인원·MVP 범위 | 게임 비전과 MVP | 제작 백로그 |
| 시간·마감·오프라인 | 핵심 반복과 시간 | 공통 상태·재접속 |
| 수요와 고객 선택 | 시장과 NPC | 경쟁·시장 검증 |
| 품질·연구·유지보수 | 운영 품질과 R&D | 업종 상세·경제 |
| 보상·비용·상품 ID | 경제와 아이템 | 원장·결제 어댑터 |
| 사건·선택 효과 | 선택과 AI 사건 | 콘텐츠 제작·개별 스토리보드 |
| 상태·명령·에러 | 공통 구현 명세 | 데이터 계약·테스트 |
| 실제 엔진·저장소·연결 | 플랫폼 구현 | 공통 포트의 합격 조건 |

## 문서와 검증 ID

OV는 개요, EXP는 경험, QA는 검증 문서다. 기능 테스트 F01~F24, 기술 테스트 T01~T24, 화면 테스트 U01~U08을 구분한다. 공통 튜토리얼은 TUT00~TUT11, 공통 스토리보드는 CT01~CT08, 업종별 스토리보드는 CF/FD/SW/SI 접두사를 사용한다.

ID는 보여 주는 제목과 분리한다. 번역·제목 변경으로 ID가 바뀌지 않는다. 단계 이름만 비슷하다고 서로 같은 이벤트로 처리하지 않는다.
